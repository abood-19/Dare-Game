# جرأة ولا حقيقة — Truth or Dare

## الملفات
- `index.html` — اللعبة كاملة (التصميم + اللعب المحلي + الأونلاين + الشات + الصوت)
- `i18n.js` — نصوص الواجهة بأربع لغات (عربي، إنجليزي، روسي، أوزبكي)
- `q_light.js`, `q_medium.js`, `q_spicy.js`, `q_hot.js` — الأقسام الأربعة، كل قسم 100 بطاقة (75 حقيقة + 25 تحدي) بالأربع لغات
- `peerjs.min.js` — مكتبة الاتصال الأونلاين (WebRTC)
- `questions.csv` — كل الأسئلة بجدول واحد للمراجعة (بيفتح بإكسل أو Google Sheets)

## الرفع على GitHub Pages
1. افتح الريبو `lgstudio-z/Dare-games` على GitHub.
2. Add file ← Upload files، واسحب كل الملفات (ما عدا `questions.csv` و `README.md` إذا ما بدك إياهم).
3. اضغط Commit changes. بعد دقيقة أو دقيقتين الموقع بيتحدث على:
   https://lgstudio-z.github.io/Dare-games/

## كيف بيشتغل الأونلاين
- ما في قاعدة بيانات ولا حساب: المضيف بيعمل غرفة بكود من 5 حروف، والباقي بيدخلوا بالكود أو بالرابط.
- الاتصال مباشر بين الأجهزة (WebRTC) عبر خادم PeerJS المجاني، والصوت بيمشي بنفس الاتصال.
- كل لاعب بيشوف البطاقة بلغة جواله، والشات بيترجم تلقائياً للغة كل واحد.
- إذا المضيف طلع، الغرفة بتسكر.

## تعديل الأسئلة
كل سطر بملفات `q_*.js` بهالشكل:
`["t", "عربي", "English", "Русский", "O'zbek"]` — `t` يعني حقيقة و `d` يعني تحدي.
